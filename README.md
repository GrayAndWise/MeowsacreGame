# MeowsacreG
a cute but scary game about kitties
Inspired by FNAF type games.

## 🚀 Projekto Statusas: Done
Šis žaidimas yra sukurtas Programavimo Inžinerijos projektui.

## 🛠️ Funkcijos (Features)
**Pilnas Game Loop:** Veikiantis žaidimo ciklas (pradžia, žaidimas, pabaiga).
**Unikalus Artwork:** Visi vizualiniai elementai ir piešiniai sukurti ranka specialiai šiam projektui.
**Priešų AI:** Kuriamas intelektas pagrindiniams žaidimo priešams.
**Kamerų sistema:**: Priešo stebėjimas naudojant kameras.

## Sistemo reikalavimai
Žaidimas yra lengvesnis už tuščią Word dokumentą, todėl paleisite praktiškai ant bet ko, kas turi ekraną.

**OS:** Windows, macOS arba Linux (jei pasileidžia YouTube, pasileis ir šitas).
**RAM:** Bent 2-4 GB (kad liktų vietos atidarytam naršyklės langui).
**GPU:** Integruota (palaikanti bent jau vaizdo rodymą).
**Vieta diske:** Mažiau nei užima viena nupiešta iliustracija (~50 MB).
